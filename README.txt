YOGASELVAM — BLACK / ELECTRIC BLUE PORTFOLIO

RUN LOCALLY
1. Extract YogaSelvam_R_MASS_Portfolio.zip.
2. Open index.html in Chrome, or open the folder in VS Code and use Live Server.
3. Keep portrait-cutout.png and resume.pdf beside index.html.

FEATURES
- Black and electric-blue visual system, responsive navigation and mobile layout.
- Animated particle network, ambient blue glow, ticker and scroll progress.
- Portrait cutout with animated neon frame/orbits and subtle 3D pointer tilt.
- Typewriter headline, reveal transitions, project filters and interactive cards.
- Featured projects auto-slide (pause on hover, arrows, swipe); 8 more under All Projects with filters.
- Click any of the 4 skill boxes to see every language/tool and the projects it was used in.
- Freelance section, badge and ticker mention.
- Resume download, email, GitHub and LinkedIn links.

CONTENT
Resume details are populated from the supplied resume. Project demo/source links were not supplied, so no fake links are shown.

TECH
HTML5, CSS3, vanilla JavaScript. No npm install required.
